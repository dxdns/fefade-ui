### Theme configuration

This setup allows the user to define **partial** theme colors. That means it's
not required to specify every color — only the ones you wish to customize. Any
colors not explicitly defined will automatically fall back to the default
values.

Import necessary modules and create a custom theme configuration.

```svelte
<script lang="ts">
	import { createTheme, Provider } from "@fefade-ui/svelte"

	let { children } = $props()

	const theme = createTheme({
		colors: { light: { bg: "orange" } }
	})
</script>

<Provider {theme} defaultThemeMode="dark">
	{@render children()}
</Provider>
```

### Accessing Theme Colors

You can access and use theme colors throughout your components. For example, you
might want to use colors defined in the theme for different parts of your app.
