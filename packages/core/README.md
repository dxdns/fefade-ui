<h1 align="center">Fefade UI Core</h1>

[![license](https://img.shields.io/github/license/fefade/ui)](https://github.com/fefade/ui/blob/master/LICENSE)
![Zero Dependencies](https://img.shields.io/badge/dependencies-0-green)

**@fefade-ui/core** is the foundation of the Fefade UI ecosystem.

It provides the shared styling layer, theme system, common APIs, and reusable
utilities used across all Fefade UI packages.

> Designed as the foundation of the ecosystem, while exposing utilities and
> theme APIs that can also be used directly in your applications.

## Features

- Shared styling infrastructure
- Theme system
- Reusable utility functions
- Common APIs shared across Fefade UI packages
- Zero external dependencies
- Fully typed with TypeScript

## Use Cases

Use `@fefade-ui/core` to:

- Build custom UI on top of the Fefade UI design system.
- Access the shared theme system.
- Reuse utility functions throughout your application.
- Share the same styling foundation used by other Fefade UI packages.

Framework-specific packages, such as `@fefade-ui/svelte`, build on top of
`@fefade-ui/core` to provide ready-to-use UI components.
