## Props

### Timer

| Prop            | Type                                              | Default | Description                                                     |
| --------------- | ------------------------------------------------- | ------- | --------------------------------------------------------------- |
| `bind:duration` | `number`                                          | `0`     | The current duration of the timer in seconds. Two-way bindable. |
| `stopped`       | `boolean`                                         | `false` | If `true`, the timer stops counting.                            |
| `onChange`      | `(value: number, valueFormatted: string) => void` | —       | Callback triggered whenever the timer value changes.            |
| `style`         | `string`                                          | —       | Inline styles applied to the timer component.                   |
